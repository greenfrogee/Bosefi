# Bosefi (Boateye Settings Fixer)

## What is Bosefi?
Bosefi is a one-click program for setting Boateye settings for Minecraft Speedrunning. Ninjabrainbot Settings, Minecraft Settings, and Toolscreen Settings are handled automatically, allowing for an extremely fast setup, while also reducing the chance of common problems occurring.

Bosefi only works on Windows. Most features will most likely break for MacOS or Linux operating systems.

## Usage

> [!NOTE]
> Make sure you've installed Toolscreen and have launched Ninjabrainbot before doing this.

1. Download the latest jar [here](https://github.com/greenfrogee/bosefi/releases/latest).
2. Launch Minecraft.
3. Make sure your sensitivity in `Options` > `Controls` > `Mouse Settings` is set to what you want it to be.
4. Make sure your Global Sensitivity in `Toolscreen` > `Basic` is set to 1.
5. Run the jar file by double clicking it.
6. Close Minecraft. Do not touch any other settings in Minecraft or they may not properly apply.
7. Relaunch Minecraft.
8. Relaunch Ninjabrainbot and press Reset.
9. Boateye should now be fully configured!

## Features
Automatically configures the following:
- All Ninjabrainbot settings
- Options.txt sensitivity and standardsettings.json sensitivity (godsens)
- Toolscreen global sensitivity (godsens)
- Toolscreen eyezoom macro heights
