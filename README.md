# Bosefi (Boateye Settings Fixer)

## What is Bosefi?
Bosefi is a program for correcting Boateye settings for Minecraft Speedrunning. Ninjabrain Bot Settings, Minecraft Settings, and Toolscreen Settings are all handled automatically.

Bosefi only works on Windows. Features will break on MacOS or Linux operating systems.

## Usage
1. Download the latest jar [here](https://github.com/greenfrogee/bosefi/releases/latest).
2. Launch Minecraft.
3. Make sure your sensitivity in `Options` > `Controls` > `Mouse Settings` is set to what you want it to be.
4. Run the jar file by double clicking it. **Follow any instructions Bosefi gives you.**

Boateye is now fully configured!
